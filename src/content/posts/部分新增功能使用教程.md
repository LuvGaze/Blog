## 📝 文章（Posts）

在 `src/content/posts/` 下新建 `.md` 文件即可发布一篇博客。

```markdown
---
title: "文章标题"
published: 2026-09-06      # 发布日期（必填，YYYY-MM-DD）
updated: 2026-09-06        # 可选，更新日期
description: "列表页显示的摘要"
image: api                 # 封面图，填 api 自动生成，或填图片 URL
tags: [标签一, 标签二]
category: "博客指南"
pinned: true               # true 置顶
draft: false
comment: true
password: "123456"         # 可选，设置后加密访问
passwordHint: "密码提示"
author: "你的名字"
---

这里是正文，支持完整的 Markdown 语法。
```

> 💡 **快捷命令**：也可以用 `pnpm new-post "标题"` 一键生成文章文件。

## 🔖 网站导航（Website）

在 `src/content/website/` 下每个文件代表一个网站，字段：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `name` | ✅ | 网站名称 |
| `url` | ✅ | 网站链接 |
| `icon` | 可选 | 图标，支持图标库（如 `material-symbols:home`）或图片 URL |
| `description` | 可选 | 简介 |
| `category` | 可选 | 分类，默认 `未分类` |
| `tags` | 可选 | 标签数组 |
| `color` | 可选 | 主题色 |
| `image` | 可选 | 预览图 |
| `featured` | 可选 | `true` 置顶展示 |
| `order` | 可选 | 排序权重 |

```markdown
---
name: GitHub
url: https://github.com
icon: https://github.githubassets.com/favicons/favicon.svg
description: 代码托管平台
category: 常用网站
order: 1
---
```

## 📓 笔记本（Notebooks）

笔记本是一个文件夹，里面放一个 `_index.json` 描述笔记本本身，再放若干 `.md` 文件作为日记/笔记。

**1️⃣ 建文件夹 + `_index.json`**（`src/content/notebooks/my-notebook/_index.json`）：

```json
{
  "name": "我的日记本",
  "cover": "https://example.com/cover.jpg",
  "summary": "记录生活的点滴"
}
```

**2️⃣ 写一篇笔记**（`src/content/notebooks/my-notebook/日记一.md`）：

```markdown
---
title: "第一篇笔记"
date: 2026-09-06
tags: [生活, 感悟]
image: ["photo1.jpg", "photo2.jpg"]
---

这里写笔记正文……
```

> ⚠️ **注意**：笔记正文文件的 `title` 字段必须填写，相册/列表中才会显示正确的标题。

## 📚 书架 / 🎬 影视 / 🎮 游戏 / 🎵 音乐（Bangumi）

书架、影视、游戏、音乐共用一个数据源结构，字段非常接近。按目录区分：

| 内容 | 目录 | `category` |
| --- | --- | --- |
| 书籍 | `src/content/books/` | `book` |
| 影视（电影/剧/动漫/纪录） | `src/content/movies/` | `real` |
| 游戏 | `src/content/games/` | `game` |
| 音乐 | `src/content/movies/` | `music` |
| 番剧¹ | `src/content/movies/` | `real` + `subcategory: anime` |

### 字段说明

| 字段 | 说明 |
| --- | --- |
| `title` | 作品名（必填） |
| `name_cn` | 中文名（可选） |
| `category` | `book` / `real` / `game` / `music` / `anime` |
| `subcategory` | 影视类可填 `movie` / `tv` / `anime` / `documentary` |
| `status` | 状态（数字，见下表） |
| `image` | 封面图 URL |
| `score` | 评分 `0.0 ~ 10.0` |
| `comment` | 短评 |
| `tags` | 标签数组 |
| `date` | 年份/日期，如 `2024-01-01` |
| `link` | 相关链接 |
| `metingServer` + `metingId` | 音乐用，接入 Meting 自动获取音频/封面/歌词 |

### `status` 状态值

书籍使用「读」，其余使用「看」：

| status | 书籍 | 影视/游戏/番组/音乐 |
| --- | --- | --- |
| `1` | 想读 | 想看 |
| `2` | 读过 | 看过 |
| `3` | 在读 | 在看 |
| `4` | 搁置 | 搁置 |
| `5` | 抛弃 | 抛弃 |

### 示例：书架

```markdown
---
title: 查理九世
category: book
image: https://example.com/book-cover.jpg
score: 9
status: 2
comment: 儿童冒险系列经典
tags: [小说, 冒险]
---
```

### 示例：音乐（接入音频与歌词）

```markdown
---
title: 故乡的云
category: music
metingServer: netease
metingId: "1901371647"
score: 9.5
---
```

> 填写了 `metingServer`/`metingId` 后，音乐页会自动解析音频、封面与歌词，无需手工填 `audioUrl`。
> 如需手动指定，也可直接填 `audioUrl` 与 `lrcUrl`。

## 🖼️ 相册（Gallery）

在 `src/content/gallery/` 下每个文件是一个相册。

```markdown
---
name: 2026 夏
description: 夏天的照片
location: 厦门
date: 2026-08-01
tags: [旅行, 夏天]
cover: https://example.com/cover.jpg
images:
  - https://example.com/1.jpg
  - https://example.com/2.jpg
---
```

> 📁 **小技巧**：如果不填 `images` 数组，会把 `public/gallery/<相册名>/` 目录下的所有图片当作该相册的图片，按文件名排序展示。

字段支持：`name`、`description`、`location`、`date`、`tags`、`password` + `passwordHint`（加密相册）、`images`（图片 URL 数组）、`cover`（封面图）。

## 🧭 足迹（Travel）

在 `src/content/travel/` 下每个文件代表一个地点，正文部分写详细游记，访问 `/travel/<文件名>/` 查看。

```markdown
---
title: 北京市
date: 2024-05-03
cover: https://example.com/cover.jpg
province: 北京          # 省份，用于地图点亮
city: 朝阳区            # 城市/区县，用于地图定位
visitCount: 3           # 访问次数，会显示在地图统计里
lat: 39.9042            # 可选，纬度
lng: 116.4074           # 可选，经度
tags: [旅行]
---

这里是该地点的游记正文……
```

> 🗺️ 足迹页（`/travel/`）使用的是高德地图：默认显示省界，放大后显示市界；`province` + `city` + `visitCount` 三个字段决定了地图上哪个区域被点亮。

## 📋 规划（Plans）

在 `src/content/plans/` 下，每个文件一条规划/待办。

```markdown
---
name: 完善其余内容
time: 随时
description: 规划描述
cover: https://example.com/cover.jpg   # 可选封面
updated: 2026-08-24
---

## 具体事项

- 补充文章
- 整理相册
```
常用字段：`name`、`time`、`description`、`cover`、`updated`（更新时间，用于排序）。

## 💰 账单（Bills）

在 `src/content/bills/` 下，每个文件一条收支记录。

```markdown
---
title: 健身房会员
amount: 399            # 金额
type: expense          # expense=支出 / income=收入
category: 运动         # 分类，影响统计与排行
account: 银行卡        # 账户
date: 2026-09-04       # 日期 YYYY-MM-DD
time: "09:00"          # 时间 HH:MM
description: 季度会员费
tags: [健康]
---
```

> 📌 `type` 必填且只能是 `income` 或 `expense`；`date` 必填；`time` 格式为 `HH:MM`。收入的分类名（如 `工资`、`人情收礼`）会自动汇总到「本月分类收入」；**金额为 0 的分类不会展示**。

## 🕘 更新日志（Changelog）

在 `src/content/changelog/` 下，文件名建议用版本号（如 `v2.0.2.md`）。

```markdown
---
version: "v2.0.2"
date: "2026-09-06"
time: "20:30"
type: "feature"          # feature / improvement / fix / removal
description: "一句话概述"
---

## 新增功能
- ...

## 优化改进
- ...
```

| type | 含义 |
| --- | --- |
| `feature` | 新功能 |
| `improvement` | 改进 |
| `fix` | 修复 |
| `removal` | 删除/移除 |

更新日志页在导航「关于 → 更新日志」中查看。

## ⚙️ 常见配置

多数全局配置在 `src/config/` 下：

| 文件 | 作用 |
| --- | --- |
| `siteConfig.ts` | 站点信息、功能开关（`pages.xxx`） |
| `navBarConfig.ts` | 导航栏链接与菜单结构 |
| `themeConfig.ts` | 主题色、字体、布局 |
| `commentConfig.ts` | 评论系统（Artalk / Giscus / Waline …） |
| `musicConfig.ts` | 音乐播放器、歌单、Meting API、歌词颜色 |
| `footerConfig.ts` | 页脚内容与版权开关 |
| `billsConfig.ts` | 账单页相关参数 |

> 音乐页的歌词「已唱/未唱」颜色、默认歌单、Meting 接口都可在 `src/config/musicConfig.ts` 中调整；也可在后台管理「音乐播放器配置」中可视化修改。

## ⚠️ 注意事项

- **日期格式**：一律使用 `YYYY-MM-DD`；时间使用 `HH:MM`。
- **图片路径**：支持远程 URL，或相对 `src/content/` 的相对路径。
- **排序规则**：书架/影视/游戏按“状态”分组（在用→已看→想看→搁置→抛弃），同状态下按评分降序；其余多数按日期倒序。
- **缓存**：修改内容后需要重新构建（`pnpm build`）或重启开发服务器才会更新。
