## 新增功能

- **关于页还原参考模板的交互组件**：正文里可悬浮的「站长资料卡」（hover 显示头像/昵称/角色/简介）、带头像的聊天气泡、双列社交链接网格、可折叠展开的技术栈手风琴、带入场动画的站点演进时间线
- **资料自动读取配置**：头像、昵称、社交平台自动取自 `profileConfig`，无需在正文重复维护；社交链接网格按 links 自动生成并带上各平台品牌色（QQ/GitHub/RSS 等）
- **技术栈按本站实际依赖整理**：分为核心框架 / 体验与动效 / 内容与渲染 / 部署与数据 / 工程化五组，鼠标可点开折叠查看每项名称、简介与官网链接

## 优化改进

- **关于页由纯文本 `.md` 改为 `.mdx` 组件化内容**：正文（介绍、Q1/Q2/Q3）可直接在 mdx 里编辑，增删社交条目、技术栈分组、时间线节点时去对应 `src/components/about/` 下的 `.astro` 数据数组改即可
- **样式适配本站单主色体系**：参考模板的青色调统一替换为 `var(--primary)`，缺失的 CSS 变量（`--tag-graph-surface`、`--article-title-marker` 等）映射到本站 `--card-bg`、`--primary`，明暗主题表现一致

## 修复问题

- 修复技术栈手风琴中 Swup 条目图标名无效的问题：改用存在的 `material-symbols:transition-fade`
