## 新增功能

- **友链与推文同页双视图**：`/friends/` 顶部增加「友链 / 全部动态」切换，全部动态沿用网格、排序与分页；支持 `?tab=feed` 直达推文视图
- **单友链动态弹层**：点击卡片上的「动态」按钮，弹出该站点最近文章的独立弹层，支持遮罩与 Esc 关闭、正文滚动锁定
- **友链卡片截图**：新增可选 `screenshot` 字段，截图作为卡片主视觉并按原比例展示；加载失败时自动退回纯头像卡
- **文件夹即分组**：`src/content/friends/<分组>/<站点>.md` 按文件夹归类，分组标题、说明与排序统一放在 `_index.json`

## 优化改进

- **友链卡片自适应高度**：移除固定 7:5 比例，信息区改为正常文档流，卡片高度随截图比例与描述长度自然变化
- **友链瀑布流**：网格由 `grid` 改为 CSS `columns`，桌面 3 列 / 平板 2 列 / 手机 1 列，卡片按列错落排布
- **动态按钮按需显示**：空闲时预取一次友链数据，只在确有文章的站点上显示「动态」按钮，避免点开只有空状态
- **添加友链入口**：在「全部动态」视图点击「添加友链」时，先自动切回「友链」视图，再平滑滚动到评论区
- **字段精简**：友链 `.md` 不再需要 `group` 与 `tags`，分组完全由文件夹推导，schema 与类型定义同步删除这两个字段
- **文档同步**：README 与《博客功能使用教程》更新为文件夹分组、`_index.json` 与 `screenshot` 写法

## 修复问题

- **动态弹层偏下**：页面容器的 `transform` 会让 `position: fixed` 相对容器定位，改为把弹层挂载到 `document.body` 后居中显示
- **少量友链分组不可见**：友链数量不超过「新朋友」上限时，独立区块会把所有友链掏空，现改为直接按分组展示全部友链
- **悬停全屏图片**：友链卡片悬停时误触发未设样式的大图预览，原图按 6068×3200 原始尺寸铺满视口，已移除该预览脚本

## 移除功能

- **友链悬浮大图预览**及其 `friends-feed:open` 事件派发，悬停只保留卡片自身的截图与光晕效果
