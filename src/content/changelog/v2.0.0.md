## 新增功能

- 全新 **后台管理系统（Blog-Admin）** 上线，与前端分离、独立运行
- 支持对 **文章、书架、影视、游戏、番组、音乐、相册、足迹、友链** 等内容进行统一管理
- **配置可视化编辑**：站点、导航、主题、评论、音乐等配置可在后台直接修改
- **Markdown 文件解析上传**：后台可解析并写入 `src/content/` 下的内容文件
- 后台引入 **JWT 认证** 与 **bcrypt 密码加密** 保障安全

## 优化改进

- 改写 `admin` 目录为 Express + TypeScript，结构更规范
- 完善内容文件的上传、编辑、删除链路，减少手写 YAML 出错率
