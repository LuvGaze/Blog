## 新增功能

- **顶部时间问候卡**：按 0–5、5–7、7–9、9–11、11–13、13–15、15–17、17–19、19–21、21–24 十个时段分别给出问候语，并搭配文字表情；支持每日一换的风景插画、实时时钟与日期，桌面端与移动端多实例同步更新
- **完整天气组件**：实况天气与体感温度、最高最低温、逐时预报、未来三天预报、湿度/风速风向/能见度/紫外线/气压/云量六项详情、日出日落，以及「今日提示」出行建议
- **今日提示**：根据实况与当日预报自动生成最多三条建议——降水带伞、雷电避险、高温防暑、低温添衣、昼夜温差备外套、高湿通风、干燥补水、大风防坠物、低能见度减速、紫外线防晒；天气平稳时提示适宜户外活动
- **博客专属右键菜单**：替换浏览器默认菜单，提供站内常用入口
- **自定义光标**：支持 png / gif / svg / cur / ico 图片光标，可分别设置普通状态与链接悬停状态；未配置图片时保持系统默认箭头
- **三岛玻璃导航**：左侧站点标识、中部主导航、右侧功能入口三段式悬浮胶囊，毛玻璃、内描边与阴影对齐参考站点

## 优化改进

- **导航结构重组**：按内容类型归并为 主页 / 文章 / 记录 / 娱乐 / 生活 / 关于 六组，不再限制子项数量，子项按实际内容量自然增减
- **导航栏收敛**：限制整条导航最大宽度，左右两段向中间靠拢；移除搜索入口与左右滑动高亮，中部导航在 1280px 以下隐藏
- **移动端精简**：底部抽屉由 8 个组件减至 5 个（保留个人、公告、时间问候、天气、统计）；导航菜单面板限制最大高度与宽度并支持滚动
- **构建体积优化**：移除页面中默认关闭却仍参与打包的 Live2D / Spine 运行时；修复文章页图片 glob 误将整个源码目录纳入构建依赖图的问题，最大的 650KB 分包消失；Pagefind 仅在搜索页按需加载
- **字体本地化**：字体在构建期下载并做子集化，产物落在 `dist/_astro/fonts`，不再依赖访客网络

## 修复问题

- **天气界面错版**：图标原先以内联 SVG 输出且缺少宽高，浏览器按默认尺寸渲染导致时钟与云图标巨大、布局错位，改用 astro-icon 后由字号控制大小
- **问候语重复 ID**：桌面与移动端同时渲染时所有 `id` 重复，只有第一处能刷新，改为 `data-*` 选择器后多实例各自更新
- **顶栏隐藏不彻底**：隐藏位移不足且缺少过渡动画，向下滚动时仍露出一条边、回滚向上时瞬间出现，改为位移出视口并补齐缓动

## 移除功能

- **账单模块**：9 个图表组件、页面、配置与数据适配器全部移除
- **可视化音乐**：音频分析、歌词层、三维场景与控制器组件及页面、样式全部移除
- **重复组件**：删除 `components/widget/SpineModel.astro`，统一使用 `components/features/SpineModel.astro`
- **顶部搜索入口**与导航左右滑动高亮效果
