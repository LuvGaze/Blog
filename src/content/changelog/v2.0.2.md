## 新增功能

- 新增 **账单系统**，支持收支流水、月度统计、分类排行、日历视图与余额管理
- **足迹地图** 升级为高德（AMap）风格：接入省界/市界按缩放动态显示、去过的区域自动点亮
- **音乐播放器** 重构：新增 3D 可视化、滚动歌词、底部歌词条与进度高亮

## 优化改进

- 账单、年度结余、本月收支等卡片全面适配站点明暗主题
- 音乐加载增加多 API 兜底，主接口限流时自动切换可用源
- 更新日志、关于我等导航组织更清晰

## 修复问题

- 修复地图空安全码导致底图白屏的问题
- 修复歌词颜色配置不生效的问题
- 修复账单流水分页过多、分类出现零金额占位的问题
