## 新增功能

- **后台侧栏组件可切换左/右栏与排序**：每个侧栏组件面板顶部新增「组件位置」快捷控制，直接选择归属侧（左侧栏/右侧栏）并设排序（越小越靠前），一键保存，无需改动源码
- **后台可补充组件可选字段**：侧栏组件面板新增「＋ 添加可选字段」，可在线补充 `side`、`order`、`showTitle`、`position`、`showOnPostPage` 等字段；后台引擎支持为对象数组元素新增缺失的标量属性
- **后台新增多项配置**：天气预报、恋爱计时器、全站访问口令均可在后台直接修改
- **后台访问口令可直接勾选页面**：受保护页面由手动填路径改为「栏目勾选」（相册/书架/游戏/影视/足迹/规划/笔记本/账单/全部文章等一键勾选），也保留自定义路径输入
- **后台个人资料支持背景图**：头像、昵称/简介字号、背景图及透明度可在线编辑
- **右侧边栏新增「最近更新」**：带封面缩略图与栏目徽章，聚合文章/书架/游戏/影视/规划/足迹/相册等最新内容，数量可在后台调整
- **恋爱计时器移到右侧栏顶部**：整块移动到右侧栏最上方展示
- **书架卡片升级为参考模板 3D 书卡**：封面整铺无文字区，比例 25:36，悬停时书体沿 Y 轴倾斜 30° 并放大、侧移，右侧有纸质厚度与封底，观感同参考模板

## 优化改进

- **站点统计运行时长改用年月日**：如「1年2月3日」「4月5日」「6日」「7年8日」，不再只显示总天数
- **恋爱计时标题只显示天数**：小部件名称由「N年M月D天」改为「N 天」，如「100 天」，直观简洁
- **天气底部三列整组轮换**：湿度/风力/空气质量三列同屏整组切换（每组固定 3 项 + 圆点指示），右侧同显「高/低温」与「AQI」；去掉能见度与悬停 3 天预报
- **天气预报标题与各小组件保持一致**：「天气预报」字号、字重与公告/音乐等组件标题统一；右侧 AQI 的文字颜色、字号与「高/低温」保持一致，不再按污染等级变色
- **气压单位改为千帕**：气压由 hPa 改为 kPa（1 hPa = 0.1 kPa，标准大气压约 101.3 kPa），更符合常用单位
- **侧边栏日历移到左侧**：日历组件从右侧栏移到左侧栏音乐下方
- **「最近更新」补全数据源**：除文章/规划/足迹/相册外，新增书架/影视/游戏、笔记本及笔记；并为书架/影视/游戏补上 `date` 字段让其正常参与时间排序；显示数量可在后台调整（默认 6）
- **网站导航分类栏背景透明**：分类 Tab 容器背景改为透明，仅保留描边，文字/徽章跟随主题明暗
- **侧边栏网格负偏移生效**：`gridEdgeX` 为负数时网格向两侧外扩（侧栏更贴边/突出），不再被 CSS 钳制为 0
- **更新日志页翻新**：可手选相关日志、点击跳转详情页、适配主题
- **顶栏子页联动父栏高亮**：位于下拉子页时父级导航高亮
- **修复随机文章在 SPA 切换文章后不更新**

## 修复问题

- 修复「最近更新」文章封面：`image: api` 的文章正确生成随机封面，不再显示占位串导致裂图
- 修复网站导航分类栏与站点主题不协调的显示问题
- 修复文章详情页切换时随机文章列表不刷新
